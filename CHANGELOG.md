# Changelog

Все заметные изменения этого проекта задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [2.1.0] — 2026-11-10

Приведение проекта к релизному качеству после аудита (см. `CODE_REVIEW.md`).

### Добавлено

- Единый модуль расчёта `src/shared/calc.js`: формулы, валидация и модель отчёта
  используются и интерфейсом, и главным процессом, и тестами.
- 37 юнит-тестов (`node:test`) на формулы, хранение данных и сборку отчётов.
- Автопроверка приложения `npm run smoke` — 22 проверки: интерфейс, безопасность,
  оба режима расчёта, валидация, история, сборка Excel и PDF.
- Экспорт истории в CSV (открывается в Excel, разделитель `;`, BOM).
- Проверка ввода с подсказками под полями и `aria-invalid`; ввод понимает
  пробелы, точку и запятую, знак `%`.
- Ввод процента премии числом (слайдер остался), диапазон 0–100 %.
- Запоминание последней папки сохранения и размера/позиции окна.
- Кнопка «Папка с данными» и версия приложения в интерфейсе.
- Автомиграция данных из папки `raschet-rentabelnosti` в `bonus-calc`.
- ESLint + Prettier, конфиги и команды `lint`, `format`, `check`.
- CI на GitHub Actions: формат, линтер, тесты, сборка приложения.
- Лицензия шрифта Roboto (SIL OFL 1.1) и список сторонних компонентов в `LICENSES/`.
- Поддержка BMP-кадров в `.ico` (Windows корректно показывает мелкие размеры).

### Изменено

- Electron 25 → 45, `sandbox: true`, обновлённый CSP без `unsafe-inline`.
- Отчёты Excel и PDF строятся из одной модели отчёта: одинаковые формулировки,
  порядок строк и суммы; итоговая строка выделена.
- Интерфейс переработан: разметка, стили и логика разнесены по файлам,
  обе панели используют один код вместо двух копий.
- Экспорт больше не открывается «поверх» приложения: диалоги модальны к окну.
- История хранится с версией схемы (`schemaVersion: 2`), старые файлы мигрируют.
- Сборка идёт по явному списку файлов; иконки генерируются перед сборкой.
- Название приложения приведено к одному виду: «Калькулятор премии».

### Исправлено

- Excel-отчёт в «Расчёте 1»: заголовок «Результаты расчёта» больше не затирает
  строку «Процент премии», а жирным выделена именно итоговая премия.
- Ставка `0 %` больше не заменяется на `20 %` (ошибка `parseFloat(...) || 20`).
- Экспорт больше не может выгрузить расчёт другой вкладки: у каждой панели свой
  снимок данных, а изменение полей блокирует экспорт до пересчёта.
- Убрано двойное хранение настроек (localStorage + файл) — источник правды один.
- Очистка истории требует подтверждения; удаление и очистка не теряют данные молча.
- Ошибки сохранения файлов показываются понятным текстом (файл занят, нет места).
- Убыточная сделка: налог на прибыль больше не становится отрицательным.
- Загрузка записи из истории восстанавливает ставки НДС и налога этой записи.
- Имена файлов отчётов корректны для любых символов в названии компании.

### Безопасность

- `sandbox: true` для процесса интерфейса, отключены разрешения (камера, микрофон).
- Главный процесс пересчитывает суммы сам и не доверяет числам из интерфейса.
- Единственный экземпляр приложения: два окна больше не затирают общую историю.
- Атомарная запись JSON с резервной копией и восстановлением после повреждения.
- `npm audit` без уязвимостей (`overrides` для `brace-expansion` и `uuid`).
- DevTools отключены в собранной версии.

### Сборка

- Установщик больше не содержит служебные файлы: посторонний бэкап (64 МиБ),
  конфигурацию ИИ-ассистента, source maps и отладочные файлы библиотек.
- Установщик собирается из чистого клона (иконки генерируются перед сборкой).
- `build/` больше не нужен в git; `.gitignore` приведён в порядок.

### Удалено

- Устаревшие файлы: `renderer.js`, `process-logo.js` и `make-icon.js` в корне
  (переехали в `scripts/`), `background.jpg`, пустые логи запуска.
- Мёртвая настройка `saveDir` (заменена на `lastSaveDir`, которая работает).

## [2.0.0] — 2026-08-20

### Добавлено

- Два режима расчёта: по выручке и по марже
- Настраиваемые ставки НДС и налога на прибыль (сохраняются в localStorage и settings.json)
- История расчётов с дедупликацией и ограничением 100 записей
- Экспорт отчёта в Excel (exceljs) и PDF (pdfkit) с поддержкой обоих режимов
- Кириллический шрифт (font.ttf) для корректного PDF-экспорта
- Генерация иконок из пользовательского логотипа (process-logo.js):
    - поддержка PNG 8/16-bit, color types 0/2/3/4/6
    - авто-кадрирование по содержимому (для A4-листов)
    - скруглённые углы, боксовый ресайз
- Дефолтная иконка с символом % (make-icon.js)
- Портативная сборка (npm run dist-portable)
- GitHub Release с установщиком и портативной версией
- .gitignore для Electron-проекта
- LICENSE (MIT)
- README.md и CHANGELOG.md

### Исправлено

- Экспорт Excel/PDF для Расчёта 2 (margin-тип) — ранее обращался к несуществующим полям companyName/revenue
- НДС в Расчёте 2 — захардкоженный 22% заменён на настраиваемую ставку
- CSP блокировал весь inline-скрипт — JS вынесен в renderer.js
- Конфликт имён `const api` с `contextBridge.exposeInMainWorld('api')` — используется псевдоним `bridge`
- `sandbox: true` блокировал contextBridge — отключён
- `classList.toggle(className, force)` в Electron — заменён на явные add/remove
- Логотип не попадал в asar — перенесён из build/ в assets/
- Обработчики кнопок экспорта вызывались сразу (`exportExcel()`) вместо передачи по клику
- Title страницы не совпадал с заголовком в шапке

### Безопасность

- contextIsolation: true, nodeIntegration: false
- Content Security Policy (script-src 'self')
- Валидация IPC-данных (sanitizeCalc, toNum)
- Рендер истории через DOM API, без innerHTML (защита от XSS)
- Блокировка навигации и всплывающих окон

## [1.0.0] — первоначальная версия

- Базовый калькулятор с одним режимом расчёта
- Экспорт в Excel и PDF
- История расчётов

# Калькулятор премии (BonusCalc)

Настольное приложение для Windows: считает рентабельность сделки и премию менеджера,
сохраняет историю расчётов и выгружает отчёты в Excel и PDF.

## Что умеет

- **Два режима расчёта**
    - «Расчёт 1 · Выручка» — по выручке, закупке и логистике;
    - «Расчёт 2 · Маржа» — по готовой марже (для менеджеров).
- **Настраиваемые ставки** НДС и налога на прибыль — сохраняются между запусками.
- **История расчётов**: автоматическое сохранение, дедупликация, лимит 100 записей,
  загрузка записи вместе с её ставками, удаление, очистка с подтверждением,
  выгрузка в CSV (открывается в Excel).
- **Экспорт отчёта** в `.xlsx` и `.pdf` — с запоминанием последней папки сохранения.
- **Проверка ввода**: принимает `1 200 000`, `1 200 000,50`, `1.200.000`, `20 %`;
  подсвечивает ошибки и не даёт посчитать мусор.
- **Горячие клавиши**: `Enter` — рассчитать, `Ctrl+Enter` — рассчитать активную вкладку,
  `Esc` — снять фокус с поля.
- **Безопасная работа с данными**: настройки и история пишутся атомарно, с резервной
  копией; при повреждении файла данные восстанавливаются.

## Методика расчёта

Согласована с заказчиком 10.11.2026 — «НДС сверху на маржу»:

```
маржа           = выручка − закупка − логистика      (все суммы указаны с НДС)
НДС             = маржа × ставка НДС
прибыль до нал. = маржа − НДС
налог           = max(0, прибыль до нал.) × ставка налога
чистая прибыль  = прибыль до нал. − налог
премия          = max(0, чистая прибыль) × процент премии
```

Пример: выручка 1 200 000, закупка 600 000, логистика 0, НДС 20 %, налог 20 %,
премия 30 % → маржа 600 000, НДС 120 000, налог 96 000, чистая прибыль 384 000,
**премия 115 200 ₽**.

Формулы живут в одном месте — [`src/shared/calc.js`](src/shared/calc.js); их же
используют интерфейс, экспорт отчётов и тесты.

## Установка

### Готовая сборка

Скачайте последний релиз: https://github.com/IgorLamakin/BonusCalcApp/releases

- `BonusCalc-Setup-x.y.z-x64.exe` — установщик (ярлык на рабочем столе, деинсталляция);
- `BonusCalc-Portable-x.y.z-x64.exe` — портативная версия без установки.

> Приложение не подписано цифровой подписью. При первом запуске Windows может показать
> SmartScreen: **«Подробнее» → «Выполнить в любом случае»**.

**Требования:** Windows 10/11 (x64). Node.js не нужен.

### Из исходников

```bash
git clone https://github.com/IgorLamakin/BonusCalcApp.git
cd BonusCalcApp
npm ci        # нужен Node.js 20 или новее
npm start
```

## Данные приложения

Настройки и история лежат в `%APPDATA%\bonus-calc\`:

- `settings.json` — ставки НДС и налога, последняя папка сохранения, размер окна;
- `history.json` — история расчётов;
- `*.bak` — предыдущая версия файла на случай сбоя.

Открыть папку можно из приложения: ссылка **«Папка с данными»** внизу окна.
При первом запуске версии 2.1 данные автоматически подхватываются из старой папки
`%APPDATA%\raschet-rentabelnosti\`.

## Сборка

```bash
npm run dist            # установщик
npm run dist-portable   # портативная версия
```

Иконки собираются автоматически перед сборкой (`predist` → `scripts/process-logo.js`)
из файла `icon.png` в корне проекта, поэтому установщик можно собрать из чистого клона.

```
├── main.js                  # точка входа: окно, IPC, миграция данных

├── styles.css               # оформление

│   └── main/

│       ├── store.js         # атомарная запись JSON + резервная копия
│       ├── window.js        # окно и политики безопасности
│       ├── ipc.js           # каналы связи и экспорт отчётов
│       ├── smoke.js         # автопроверка приложения (не входит в сборку)
│       └── exporters/
│           ├── excel.js     # сборка .xlsx
│           └── pdf.js       # сборка .pdf
├── scripts/
│   ├── process-logo.js      # иконки из icon.png
│   ├── make-icon.js         # запасная иконка «%»
│   └── lib/image.js         # PNG/ICO без внешних зависимостей
├── test/                    # юнит-тесты (node:test)
├── assets/                  # логотип и иконки для рантайма
├── build/                   # ресурсы сборки (генерируются)
├── LICENSES/                # лицензия шрифта и сторонних компонентов
└── font.ttf                 # Roboto для PDF (кириллица)
```

## Безопасность

- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, CSP без `unsafe-inline`;
- интерфейс получает только перечисленные в `preload.js` вызовы;
- все данные, приходящие по IPC, повторно валидируются в главном процессе,
  а суммы отчёта пересчитываются заново — интерфейсу не доверяем;
- единственный экземпляр приложения (второй запуск поднимает существующее окно);
- DevTools и меню разработчика отключены в собранной версии.
